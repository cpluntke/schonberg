# Bug / feedback priority scale

Used by every test and review pass.

- **P0 – Blocker.** The app crashes or doesn't load. The core loop (choose piece →
  choose part → sing → see scored feedback) can't be completed. Practice
  progress is lost. Mic or pitch detection is unusable on a supported browser
  (current Chrome / Safari / Firefox, desktop or phone). Scoring is
  systematically wrong (e.g. correct singing graded as misses).
- **P1 – Major.** A main feature is broken or seriously misleading, with no
  reasonable workaround: wrong notes/rhythms/lyrics from an import, wrong
  notation labels, the mastery ladder can't be advanced or misreports levels,
  audio out of sync with the visuals, a layout unusable at phone width (390px), a
  screen you can't navigate away from, or something important that a first-time
  singer can't find out how to do.
- **P2 – Minor.** A bug with a workaround, a confusing UX, a noticeable
  feature gap, poor performance on mid-range phones, or accessibility issues
  (contrast, touch targets, keyboard).
- **P3 – Polish.** Cosmetics, copy, nice-to-haves, feature requests.
